# RSA Encryption Tool

A Python-based implementation of the RSA encryption algorithm demonstrating public-key cryptography, key generation, message encryption, and decryption.

## Overview

This project implements the RSA encryption algorithm, one of the foundational cryptographic systems used in modern cybersecurity.

The program demonstrates how asymmetric encryption works by generating public and private keys, encrypting messages using the public key, and decrypting them using the private key.

The project was developed to explore mathematical concepts behind modern encryption systems including:

- Prime numbers
- Modular arithmetic
- Public/private key cryptography
- Euler’s Totient Function
- Encryption and decryption algorithms

## Key Features

- RSA public/private key generation
- Message encryption
- Message decryption
- Modular arithmetic operations
- Prime number based cryptographic workflow
- Educational demonstration of asymmetric encryption

## How RSA Works

RSA encryption works by generating two keys:

- Public Key → Used for encryption
- Private Key → Used for decryption

The algorithm:

1. Generates large prime numbers
2. Computes RSA modulus values
3. Creates encryption and decryption exponents
4. Encrypts plaintext into ciphertext
5. Decrypts ciphertext back into readable text

This project demonstrates the full encryption workflow programmatically.
